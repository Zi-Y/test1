## 第一部分：T1

### 1. 定义（✅，小注）

五种块与论文式 (2) 一致；$c(t,d)$ 与 $d$ 无关，记作 $c(t)$ 是合理的；$|\Omega|=nTD$ 正确。

**小注 1**：论文把每个 $y_{t,d}$ 都称为 element，其中包括只出现在输入里的时刻（0 起点时 $t<L$）。这些元素的 $c(t)=0$，对应的 $B_{t,d}=\emptyset$。划分不能含空块，所以 element 划分只应包含 $t\in[L,N-1]$。

这一点也影响论文的预算规则：element 的成员数应为 $m=(n+T-1)D$。如果实现里把 $c=0$ 的元素也计入 $m$，就会多屏蔽约 $L/(N-L)$ 比例的元素（ETTh 上约 1.1%）。需要与实现核对。

### 2. Hasse 图表述（⚠️）

在 `kappa_enum.py` 中精确枚举了四组 $(N,L,T,D)$，覆盖 $T=1$、$D=1$、$n=1$ 的退化情形。精确的条件如下：
- element ⋠ window、element ⋠ chan、element ⋠ time，各自都等价于"存在 $c(t)\ge2$"，即 $T\ge2$ 且 $n\ge2$。
- window ⋠ element ⟺ $TD\ge2$；chan ⋠ element ⟺ $T\ge2$；time ⋠ element ⟺ $D\ge2$。
- time 与 chan 不可比 ⟺ $T\ge2$ 且 $D\ge2$。草稿没有写这一条，但 Hasse 图需要它。

由此得到建议的精确表述：
> 设 $n\ge2$。当 $T\ge2$ 时，element 与 window、channel row 不可比；当 $T\ge2$ 且 $D\ge2$ 时，element 还与 time column 不可比，并且 time column 与 channel row 不可比。对任意 $T,D$，都有 window ∧ element = time ∧ element = chan ∧ element = time ∧ chan = occurrence，以及 time ∨ chan = window。当 $T\ge2$ 时，window ∨ element 是只含一个块的划分 $\{\Omega\}$（相邻窗口共享目标，所有项连通），它不在五种单元之中。

所以这五种单元**不是划分格的子格**，Hasse 图只能当作偏序图来画，不能暗示存在上确界。

另外，"$T,D\ge2$"作为充分条件没有错，但 $n\ge2$ 不能省略：$n=1$ 时 element 就是 occurrence。

顺带一个有用的观察：element ∨ time column 是"按绝对时刻 $t$ 分块"的划分，块大小为 $c(t)D$，正好是 κ 表第 2 行描述的结构；element ∨ channel row 是"按通道分块"的划分。

### 3. 引理 1（✅）

若 $\mathcal P\preceq\mathcal Q$，则每个 $\mathcal Q$ 块都是它所包含的 $\mathcal P$ 块的并，所以 $\mathcal Q$ 可行集 ⊆ $\mathcal P$ 可行集，从而 $\max F$ 单调。这对任意集合函数 $F$ 都成立。

### 4. 引理 2（✅，但要注明只在前缀大小处成立）

证明正确。LP 松弛就是分数背包，其最优值等于按价值密度贪心装入的值（Dantzig）。容量恰为 $s_k$ 时，贪心解不含分数项，所以它同时是 0-1 问题的最优解。价值 $\sum_B e^2\ge0$，块非空，所以条件满足。平局时，任何一种按密度排序得到的前缀都给出同一个 LP 值，所以结论与打破平局的方式无关。

穷举核对（`lemma2_check.py`）：在 1134 个"实例 × 前缀"上，前缀与穷举最优值逐一相等，0 次失败。

需要强调，这**只在前缀大小处成立**：在**非前缀**容量下，"按密度装、装不下就跳过"的贪心有 702 次严格次优。v2 修订表中"对任意块大小都精确最优"这句话，应改为"对任意块大小，**在其前缀大小处**精确最优"。论文的预算规则正好取前缀，所以对论文本身没有问题。

**括注"§3.3 的打分规则对每种单元都是最优规则"（⚠️）**：数学上，它只在 $F$ = 打分时刻的平方残差和、且大小不超过自身前缀大小的意义下成立。
- 对等大小的块（window、time、chan、occ），这几乎就是定义本身；引理只对 element 有实质内容。
- 草稿紧接着承认"收益 ≠ 质量"，所以写成"最优规则"会让审稿人误以为论文的打分规则被证明是好的。

建议改为："按块均值取前缀，恰好是在其实际项数下最大化打分时刻移除质量的精确解；这不涉及测试误差。"

### 5. 推论（✅，并给两处修正）

当 $s$ 取较粗单元的前缀大小时，五种单元中的每一对细与粗，都满足"较粗单元的前缀大小也是较细单元的**前缀**大小"，而不只是可以实现的项数：
- window 的前缀大小是 $kTD$，它是 $D$ 和 $T$ 的倍数，也是 time、chan 的前缀大小；
- occ 可以实现任意大小。

所以三条不等式成立。

**修正 a（定义，建议）**：令 $M_{\mathcal P}(s):=\max\{F(S):S\text{ 为 }\mathcal P\text{ 块之并},\ |S|\le s\}$。那么由引理 1，$\mathcal P\preceq\mathcal Q\Rightarrow M_{\mathcal P}(s)\ge M_{\mathcal Q}(s)$ 对**所有** $s$ 成立；由引理 2，当 $s$ 是 $\mathcal P$ 的前缀大小时，$M_{\mathcal P}(s)$ 就等于论文中 $\mathcal P$ 掩码的质量。这样就不必再说"取较粗单元的前缀"，陈述也更干净。

**修正 b（⚠️ 第 9 条）**："理论只给出偏序：element 与 time column、channel row 之间的先后由数据决定"漏了 window。反例：设残差质量全部集中在一个窗口 $i$ 内，并在其 $TD$ 项上均匀分布。取 $s=TD$：
- window 取到全部质量；
- element 只能取 $D$ 个元素，每个元素在窗口 $i$ 中只有一项非零，质量只有 $D/(TD)=1/T$。

反过来，若困难是元素型的，则 element 占优。所以 element 与 window 的先后同样由数据决定。

ETTh2 的例子（time −3.31，window −3.84）与表 1 一致 ✅。更有力的例子是 ETTh2、ETTm2 上 channel row 胜过 occurrence（−5.99 对 −5.49，−6.51 对 −6.26），而 occurrence 是质量最大的单元。还要注意：论文实际的各单元项数并不相等（见第 18 条），所以"收益 ≠ 质量"严格说要在 E4（按质量匹配预算）下才能成立。

### 6. 命题 3：κ、ρ 的定义（⚠️）

1. **定义域**：κ 是按 $\text{occ}(A)$（元素集合 $A$ 的全部 occurrence）定义的，但 T1 的"注意"、T2 的双重足迹、T5 的起点带，都把 κ 用在**不是元素块之并**的 occurrence 集合上。应直接对 $S\subseteq\Omega$ 定义：
   $$\kappa_{\mathcal P}(S)=\frac{|\bigcup\{B\in\mathcal P:B\cap S\neq\emptyset\}|}{|S|},\qquad \rho_{\mathcal P}(S)=\frac{|\bigcup\{\cdots\}|}{|\Omega|},$$
   并把 $S=\text{occ}(A)$ 作为特例。

   同时应写出两条性质：
   - **单调性**：$\mathcal P\preceq\mathcal Q\Rightarrow\kappa_{\mathcal P}(S)\le\kappa_{\mathcal Q}(S)$。
   - **上界**：$1\le\kappa_{\mathcal P}(S)\le|\Omega|/|S|$，且 $\kappa_{occ}\equiv1$。

   这两条性质是第 16、17 条问题的根源。
2. **与论文预算口径不一致**：论文的 $r$ 是**成员数**的比例（$\lfloor rm+1/2\rfloor$ 个成员）。对等大小的单元，成员比例等于项数比例。但对 element：
   - 覆盖内部的元素集合 $A$ 所需的成员比例是 $|A|/((n+T-1)D)$；
   - 而 $\rho_{elem}=|A|T/(nTD)=|A|/(nD)$；
   - 两者相差 $(n+T-1)/n$ 倍，ETTh、$T=720$ 时为 1.092。

   T5 的"中和 ⇔ $r\ge\rho$"如果直接拿论文的 $r$ 去比较，对 element 会差这个因子。
3. **"所需预算"只是必要条件**：只有当排序确实把所有被触及的块排在前面时，它才是充分的（这正是 T5 的泄漏条件）。建议写成"能够完全移除 $S$ 的最小预算"。

### 7. κ 表逐格核对

在 `kappa_enum.py` 中，对 4 组参数逐个 $t$ 枚举，并对片段逐个起点枚举。

**第 1 行（单点）、第 2 行（跨通道同时刻）**：所有 $c(t)\ge1$ 的 $t$（包括两端）都没有违反 ✅。理由正如草稿所说，分子和分母都含有因子 $c(t)$：
- 单点：$|\text{occ}|=c(t)$，time、chan、win 的并分别是 $c(t)D$、$c(t)T$、$c(t)TD$；
- 跨通道：$|\text{occ}|=c(t)D$，time、chan、win 的并分别是 $c(t)D$、$c(t)DT$、$c(t)TD$。

需要补一句：$c(t)=0$ 的纯输入时刻上 κ 无定义。

**第 3、4 行（片段）**：内部数值全部正确 ✅。但"适用范围"一栏应细化（⚠️）：
- occ = 1、elem = 1、time = $D$（单通道）或 1（全通道），**在两端也精确成立**，因为每个 occurrence 恰好对应一个不同的 time column 块；
- 只有 chan、win 两列需要重算。通式如下。设片段为 $[a,b]$，被触及的窗口数为 $W=\min(n-1,b-L)-\max(0,a-L-T+1)+1$（0 起点）。则
  $$\kappa_{chan}=\frac{T\cdot W}{\sum_{t=a}^{b}c(t)},\qquad \kappa_{win}=D\,\kappa_{chan}\ (\text{单通道}),\qquad \kappa_{win}=\kappa_{chan}\ (\text{全通道}).$$
  已与枚举逐一核对，例如 $(N,L,T,D)=(40,3,5,2)$、$a=3$、$\ell=2$ 时为 10/3。
- **端点值不是内部值的上界或下界**。按论文尺寸（$L=T=96$，ETTh）计算，片段位于第一个目标时刻起：

  | $\ell$ | 端点 $\kappa_{chan}$ | 内部 $(\ell+T-1)/\ell$ |
  |---|---|---|
  | 1 | 96 | 96 |
  | 2 | **64** | 48.5 |
  | 10 | **17.5** | 10.5 |
  | 96 | 1.979 | 1.990 |
  | 500 | 1.105 | 1.19 |

  短片段在端点处的 κ 更大，长片段更小。
- **片段覆盖整个目标区间**这一极端情形：单通道时 $\kappa_{chan}=1$，$\kappa_{time}=\kappa_{win}=D$；内部公式给出的 $(\ell+T-1)/\ell>1$ 不适用。

### 8. κ 表后的"注意"：起点带（⚠️）

1. **在起点带上，κ 区分不了 channel row 与 element。** 设单通道在 $t_0$ 处发生水平平移，并且平移同时出现在输入和目标中。理想化的高残差集合是"输入完全在平移之前、目标在平移之后"的 occurrence：$\{(i,t):i+L-1<t_0\le t\}$，在 $(j,k)$ 坐标下是三角形 $0\le j\le k\le T-1$，共 $T(T+1)/2$ 项。枚举得到：
   $$\kappa_{chan}=\kappa_{elem}=\frac{2T}{T+1}\approx2,\qquad\kappa_{time}=D,\qquad\kappa_{win}=\frac{2TD}{T+1}.$$
   对称性的来源是：channel row $j$ 中高残差的比例是 $(T-j)/T$，element $t_0+m$ 中高残差的比例是 $(T-m)/T$，两者的轮廓完全相同。

   只有当高残差集合是"**输入跨越平移点**的窗口的整条通道行"（输入侧瞬态）时，才有 $\kappa_{chan}=1<\kappa_{elem}=(L+T-2)/(L-1)$（已枚举）。所以 §0.3 中"channel row 能捕捉、element 捕捉不到"需要的是后一种结构，而不是草稿描述的"起点之后约 $T$ 步"的起点带。
2. **漏了终点带**：长度为 $\ell$ 的片段结束时，"输入在片段内、目标在片段后"的窗口同样产生高残差。$\ell<T$ 时两条带会重叠。
3. **"线性模型可以用平移过的输入预测平移过的目标"需要水平等变**，即每个步长的权重和为 1，或者带 RevIN 类归一化。没有归一化、权重和不为 1 的线性模型做不到。
4. **带宽取决于滞后权重**：
   - 近似持续性预测（权重集中在最后一个滞后）时，带宽就是 $T$；
   - 权重在 $L$ 个滞后上近似均匀时，残差要在输入完全进入新水平后才会消失，带宽约为 $T+L$。

### 9. 含义 1（⚠️，过度陈述）

$TD=96\times7=672$ 正确。但"这**就是** window gains least 的定量机制"说得过头：
- 单点困难下 channel row 的 κ 是 $T=96$，比 time column 的 $D=7$ 大 14 倍；
- 可是 channel row 在 ETTh2、ETTm2 上是最好的单元，并且全面胜过 time column。

κ 只是可达性，草稿自己的"风险"一栏也这样写了。建议改为"与 window gains least 一致的一个组合因素"。

### 10. 含义 2（❌）

> "没有一个单元在所有结构上都最优（只有 occurrence 和 element 在任意目标侧结构上都是 1）"

在 κ 的意义下，**occurrence 对任意集合 $S\subseteq\Omega$ 都有 $\kappa=1$**，不只是目标侧结构，而且由引理 1，它的移除质量也处处最大。所以 occurrence 恰恰在所有结构上都最优，括号里的话直接否定了结论。§4 表中"证明'某单元最优'不成立（T1 表明不存在对所有结构都最优的单元）"错在同一处。

**能成立的版本**：
- "**除 occurrence 外**，没有一个单元对所有结构（包括上下文侧）的 κ 都为 1：element 对目标侧结构为 1，但对输入足迹为 $(L+T-1)/L$；channel row 对输入足迹为 1，对单点为 $T$。"
- "occurrence 并非在收益上处处最优（ETTh2、ETTm2 上 channel row 更好）"是**经验事实**，T1 解释不了，需要 κ 之外的机制，例如粗单元的平均降低了打分噪声、掩码的方差代价等。

### 11. 含义 3：对齐指数（⚠️，几乎是空检验）

1. $A_r$ 取 top-r% 的 **element**，所以 $\text{occ}(A_r)$ 是元素块的并，于是 $\kappa_{occ}(A_r)=\kappa_{elem}(A_r)=1$ 是构造出来的恒等式。
2. 由单调性，$\kappa_{win}\ge\kappa_{time}$ 且 $\kappa_{win}\ge\kappa_{chan}$ 对任意数据都成立。

   所以"κ 排序"中只有 time 与 chan 的相对位置取决于数据，其余全是结构使然。只要"window 收益最小、occurrence 收益常常最大"（这已经是表 1 的事实），P2 就几乎必然"成立"，它检验不了任何假设。
3. **饱和**：$\kappa\le|\Omega|/|\text{occ}(A_r)|\approx1/r=10$。若困难元素在时间上不聚集（按比例 $r$ 独立出现）：
   - $\kappa_{chan}=(1-0.9^{96})/0.1=9.9996$，$\kappa_{win}=10.0000$，与数据集无关；
   - $\kappa_{time}$ 在 $D=7$ 时为 5.22，$D=21$ 时为 8.91，$D\ge137$ 时为 10.00。

   所以在 $r=10\%$ 下，唯一的变化来自时间上的聚集程度，而且主要由 $D$ 决定。
4. 它**无法检验 §0.3 的"上下文侧"解读**，因为按元素定义的 $A_r$ 在构造上就是"目标侧"结构。

**修正建议**：
- 改用 top-r% 的 **occurrence** 作为 $S_r$。这时 $\kappa_{elem}(S_r)$ 不再恒为 1，正好度量"高残差集合与元素的对齐程度"。
- 取较小的 $r$（例如 0.5%–2%），或者报告 $(\kappa-1)/(1/r-1)$ 这种归一化形式。
- 只把 time 对 chan、elem 对 chan 这类不可比的单元对作为检验对象。
- 按骨干分别计算，因为打分对每个"骨干 × 数据集 × 步长"各做一次。

### 12. "相同实际项数"与 §1 原则 6（⚠️）

原则 6 说"各单元实际屏蔽的项数差 $O(m_{\max}/(r|\Omega|))$，可以忽略"。
- 对 window、time、chan、occ 成立：取整误差不超过半个块。
- **对 element 不成立**：element 屏蔽 $\lfloor r(n+T-1)D+1/2\rfloor$ 个元素，每个元素含 $c(t)\in[1,T]$ 项，所以实际项数取决于**选中了哪些元素**。

`eta_budget.py` 的计算结果（实际项数 / $r|\Omega|$）：

| 数据集 | $T$ | 全选内部元素（上界） | 均匀选取 | 尽量选端点（极端下界） | 端点元素占比 |
|---|---|---|---|---|---|
| ETTh | 96 | 1.011 | 1.000 | 0.899 | 2.2% |
| ETTh | 720 | **1.092** | 1.000 | 0.325 | 16.8% |
| ECL | 720 | 1.041 | 1.000 | 0.632 | 7.9% |
| ETTm、weather、solar | 720 | 1.02 | 1.000 | 0.81–0.82 | 约 4% |

由于高分元素通常在内部，偏差的现实方向大概率是**多屏蔽**，ETTh 长步长下约 +9%。偏差还会与第 28 条的端点偏差相互作用。E4 以及所有"在相同实际项数下"的比较，都应**按实际项数**而不是按 $r$ 对齐。

### 13. P1 不是可证伪预测（⚠️）

"在相同实际项数下，移除质量满足细化偏序"是引理 1、2 的直接推论，任何数据都不可能违反，只能用作单元测试。把它列在"可证伪预测"表中，会让审稿人质疑整张表的诚意。

## 第二部分：T2

### 14. v1 可加模型不可识别（✅，补一点）

三点都正确：$(at,-ai,-ak)$ 加上 $\mu\mapsto\mu-aL$ 不改变拟合。补充一点：$\beta$ 的跨通道平均 $\bar\beta(i)$ **同样会被 $\gamma(i,t)$ 吸收**。所以只要模型里有 γ，只有通道偏差部分 $\alpha-\bar\alpha$、$\beta-\bar\beta$ 是可识别的，φ 则完全不可识别。

### 15. η² 的定义（✅）

按块大小加权，$\eta^2_{\mathcal P}=SS_B/SS_T$，也就是相关比，对给定的划分唯一定义，"与顺序无关"正确。应补写一条性质：$\mathcal P\preceq\mathcal Q\Rightarrow\eta^2_{\mathcal P}\ge\eta^2_{\mathcal Q}$（全方差公式），所以 $\eta^2_{occ}=1$，并且 $\eta^2_{win}\le\eta^2_{time},\eta^2_{chan}$ 恒成立。

### 16. "无结构基线约 $1/m_{\mathcal P}$"（⚠️）

**在 i.i.d. 零假设下**：单因素 ANOVA 给出 $\mathbb E[SS_B]=(K-1)\sigma^2$、$\mathbb E[SS_T]=(N-1)\sigma^2$。所以基线精确为 $(K-1)/(N-1)$，正态时 $\eta^2\sim\text{Beta}\big(\tfrac{K-1}2,\tfrac{N-K}2\big)$。
- 对等大小的块，这个值就是 $1/m$ ✅；
- 对 element，$K=(n+T-1)D$，基线约为 $\frac1T\cdot\frac{n+T-1}{n}$，ETTh、$T=720$ 时比 $1/T$ **高 9.2%**（0.001516 对 0.001389），ECL、$T=720$ 时高 4%。

"约"字可以接受。

**但这个零假设与任何预测残差都不相容**，按它比较会把每个数据集、每个单元都判成"有结构"：

1. **共享目标噪声**：$y_{t,d}$ 中任何不可预测的成分（时刻 $t$ 的新息）都会出现在该元素的全部 $c(t)$ 个 occurrence 中。设 $e=u_{t,d}+v_{i,t,d}$ 服从高斯，记 $\rho=\sigma_u^2/(\sigma_u^2+\sigma_v^2)$。由 Isserlis 公式 $\mathrm{Cov}(e_a^2,e_b^2)=2\,\mathrm{Cov}(e_a,e_b)^2$，可以精确得到
   $$\eta^2_{elem}\ \to\ \rho^2+\frac{1-\rho^2}{T}.$$
   $\rho=0.5$、$T=96$ 时为 0.258，是 $1/T$ 的 25 倍。
2. **随机游走加完美预测器**：这里完全没有"困难结构"，任何时刻、窗口、步长都没有特殊难度。用 Isserlis 公式精确计算：

   | | $T=96,D=7$ | 无结构基线 |
   |---|---|---|
   | $\eta^2_{elem}=\eta^2_{chan}$ | **0.448** | $1/T=0.0104$ |
   | $\eta^2_{time}$ | 0.237 | $1/D=0.143$ |
   | $\eta^2_{win}$ | 0.064 | $1/(TD)=0.0015$ |

   原因有二：同一元素的各个 occurrence 共享新息；同一通道行的各个步长共享从窗口起点开始的路径。time column 偏高则来自 φ（不同步长的方差不同）。
3. **跨数据集比较**：$D$ 从 7 变到 321，window 与 time column 的基线相差约 46 倍。所以必须用 $(\eta^2-b)/(1-b)$、$\omega^2$，或者更合适的、基于模型的零假设做归一化，否则 P3 的秩相关测到的主要是 $D$。

### 17. η² 的解释与 P3（⚠️）

- "保留了多少 occurrence **排序**信息"这一说法不准确。η² 是 $e^2$ 的二阶矩份额，由最大的几个平方残差主导（需要四阶矩），对 top-r 选择是否一致只有间接关系。
- 真正与掩码直接相关、而且与 T1 衔接的量，是：
  - **质量捕获比** $M_{\mathcal P}(s)/M_{occ}(s)\in[0,1]$（在实际项数 $s$ 处）；
  - 或者 top-r 集合的重叠率，例如 occurrence 掩码中有多少比例被 $\mathcal P$ 掩码覆盖。

  建议把它们作为主度量，η² 作为辅助。
- **与论文设置一致性**：打分对每个"骨干 × 数据集 × 步长"各做一次，而表 1 是三个骨干的平均。所以 η² 与收益必须按骨干配对，不能拿表 1 的合并均值做秩相关。

### 18. 步长剖面的 $O(T/n)$（❌，按原文表述）

原文写的是："$\hat\phi(k)$，即步长为 $k$ 的平均平方残差。若 β 有界，别名斜率 $|a|\le2B_\beta/n$，$\hat\phi$ 在 $[0,T)$ 上的误差为 $O(T/n)$。"这里把两个不同的对象混在了一起。

**(a) 原始步长均值的精确恒等式**（`step_profile.py` 核对，误差 $10^{-15}$）。在不含 γ 的模型 $e^2_{i,t,d}=\mu+\alpha(t,d)+\beta(i,d)+\phi(k)+\eta$（$t=i+L+k$）下：
$$\hat\phi(k)-\hat\phi(0)=\phi(k)-\phi(0)+\frac1n\Big[\sum_{j<k}\bar\alpha(L+n+j)-\sum_{j<k}\bar\alpha(L+j)\Big]+(\bar\eta_k-\bar\eta_0).$$
- **β 精确抵消**：每个步长都恰好看到全部 $n$ 个窗口。把 β 放大 100 倍，$\hat\phi$ 的变化只有 $5\times10^{-14}$。
- 偏差只来自 $\bar\alpha$ 在**前、后各 $T-1$ 个目标时刻**上的值，上界为 $k\cdot R_\partial/n$，其中 $R_\partial$ 是 $\bar\alpha$ 在这些端点时刻上的极差。

所以，对原始均值来说，"β 有界"**既不必要也不充分**。反例：β ≡ 0（有界），但端点处的 $\bar\alpha$ 很大（例如训练段开头或末尾有尖峰、整体方差有趋势），偏差就是 $k R_\partial/n$，可以任意大。

如果模型含 γ，$\hat\phi(k)$ 还会混入 γ 沿对角线的均值 $\frac1n\sum_i\gamma(i,i+L+k)$，φ 完全不可识别（这正是草稿第 1 点自己说的）。

**(b) 拟合可加模型时的识别宽度**。这才是"β 有界"起作用的地方。若真实的 β 与拟合的 β 都满足 $\|\beta(\cdot,d)\|_\infty\le B_\beta$，由于模型带自由常数，**紧界**是 $|a|\le4B_\beta/(n-1)$，不是 $2B_\beta/n$。紧例：$\beta=-B+2Bi/(n-1)$，$\beta'=B-2Bi/(n-1)$，两者差的斜率为 $4B/(n-1)$（脚本已构造）。只有再固定 $\beta(0,d)=0$ 这类归一化时，界才是 $2B_\beta/(n-1)$。

φ 在 $[0,T)$ 上的不确定宽度为 $4B_\beta(T-1)/(n-1)$。在 ETTh、$T=720$ 时，这等于 **$0.37B_\beta$**。β 是窗口效应，在波动期可能是平均 $e^2$ 的数倍，所以"$n\gg T$ 时可以忽略"必须改为"当 $B_\beta T/n\ll\phi$ 的极差时可以忽略"。论文中的 $T/n$：ETTh 为 0.011 到 0.092，ECL 为 0.005 到 0.041，其余数据集不超过 0.021。

**建议的精确陈述**：
> 定义 $\hat\phi(k)$ 为步长 $k$ 的原始平均平方残差。在不含 γ（或 γ 沿每条对角线均值为零）的可加模型下，上面的恒等式成立：β 不影响 $\hat\phi$，偏差只来自序列两端各 $T-1$ 个时刻的时间效应，上界为 $(T-1)R_\partial/n$。可以零成本地报告"去掉两端各 $T-1$ 个时刻后重新计算的 $\hat\phi$"作为稳健性检查。

### 19. "远步长被屏蔽得更多"（✅）与 Hounie 类比（⚠️）

- 若 $e^2=X+\phi(k)$，并且 $X$ 的**边缘分布**在各步长上相同，则被屏蔽比例 $1-F_X(\tau-\phi(k))$ 关于 $\phi(k)$ 单调不减 ✅。乘性形式 $e^2=\phi(k)X$（$X\ge0$）同样成立。
  - "可交换"是关于联合分布的条件，比需要的强，应改成"同分布"。
  - "φ 递增"是经验事实，应注明。
- 引用 Hounie et al. (2024) 时要说明**方向相反**：loss shaping 用对偶变量**上调**超出约束的（通常是远的）步长的权重，occurrence 掩码则**下调**远步长的有效权重。"部分等价于按步长重新加权"只在"都是按步长的权重"这个意义上成立。

### 20. 遗漏：各单元对 φ 的暴露不同，element 在两端有偏（⚠️，新增）

| 单元 | 块内的步长构成 | 对 φ 的暴露 |
|---|---|---|
| occurrence | 单一步长 | 完全暴露 |
| **time column** $(i,t)$ | 单一步长 $k=t-i-L$ | **完全暴露**（与 occurrence 相同） |
| channel row、window | 全部 $T$ 个步长 | φ 抵消 |
| element（内部） | 全部 $T$ 个步长 | φ 抵消 |
| element（$t\in[L,L+T-2]$，训练段开头） | 只有近步长 $k\le t-L$ | 得分被**低估** |
| element（训练段末尾 $T-1$ 个时刻） | 只有远步长 | 得分被**高估** |

所以：
- (i) "掩码等于按步长重新加权"这一效应同样存在于 time column，E5.1 应该对 time column 也设上限。
- (ii) 当 φ 递增时，element 的 top-r 会**系统性地偏向训练段末尾**的端点元素。这些元素的 $c<T$，又会与第 12 条的项数偏差耦合。ETTh、$T=720$ 时端点元素占全部元素的 16.8%，对论文的 element 结果不可忽略。建议作者零成本统计 element 掩码中端点元素的占比。

### 21. 尺度条件与时间对齐（✅）

- 内部 element 的得分含有 $\frac1T\sum_{i=t-L-T+1}^{t-L}\beta(i,d)$，是 β 长度为 $T$ 的滑动平均。所以"上下文变化的时间尺度短于 $T$ 才能被平均掉，超过 $T$ 的 regime 会留在得分里"定性正确（更准确地说，是 β 在低于约 $1/T$ 频率上的成分会被保留）。
- 时间对齐的困难：element 与 time column 都含 $\bar\alpha(t)$，κ 也都是 1 ✅。但 time column 还含 $\bar\beta(i)$ 和 $\phi(k)$，element 还含通道特有的 $\alpha(t,d)$，"看到同一个东西"宜改为"都看到 $\bar\alpha(t)$"。

### 22. 双重足迹

**目标足迹**（✅）：共 $c(t)$ 项，幅度约为 $M$（若打分模型已部分拟合了污染，幅度会小于 $M$，见 T5 中的 $\gamma_A$）。

**输入足迹（通道独立）的 κ**（`footprints.py` 枚举 ✅，限内部）：

$$\kappa_{chan}=1,\quad\kappa_{time}=D,\quad\kappa_{win}=D,\quad\kappa_{elem}=\frac{L+T-1}{L},\quad\kappa_{occ}=1.$$

"element 要以拿掉 $L+T-1$ 个干净目标的全部监督为代价"正确，附带损伤为 $(T-1)T$ 项。需要补充两点（⚠️）：
- **"$L=T$ 时约为 2"只对应论文的 $T=96$**。$L=96$ 时，$T=96,192,336,720$ 分别对应 1.99、2.99、4.49、**8.49**，应直接给出这四个数。
- 需要注明"内部"条件。例如在纯输入时刻 $t=L-1$ 处，$\kappa_{elem}=(T+1)/(2L)+(L-1)/L$，$L=T=96$ 时约为 1.49。

**输入足迹的幅度**（⚠️）：$M|W_{kj}|$ 这个线性近似本身没有问题，但应写明它的**数量级**。
- 线性预测器每个步长的权重和大致为 1（保持水平）。若权重分散在 $L$ 个滞后上，$|W_{kj}|\sim1/L$，输入足迹的平方残差约为目标足迹的 $1/L^2\approx10^{-4}$。TSLib 的 DLinear 初始化权重就是 $1/L$。
- iTransformer 与 TimeMixer 在 TSLib 中使用逐窗口归一化（RevIN 或 Non-stationary 风格）。尖峰进入均值和标准差后，归一化后的幅度约为 $\sqrt L$，**对 $M$ 有界**，线性近似失效。

所以在打分时刻，输入足迹很可能**根本不进入高分集合**。上面关于它的 κ 都要以"该足迹确实是高残差集合"为前提，否则对掩码选择没有意义。

**通道混合**（⚠️，误导）：
- 足迹是 $L$ 个完整窗口，枚举得到 $\kappa_{win}=1$ ✅，但 **$\kappa_{time}=\kappa_{chan}=1$ 同样成立**，$\kappa_{elem}=(L+T-1)/L$ 不变。所以它与 window、time、chan 三者对齐，并不特别"与 window 对齐"。
- **与论文设置不符**：论文 §4 写的是 TimeMixer "mixes scales"，不是 mixes channels。按我对 TSLib 的了解，TimeMixer 的 `channel_independence` 默认为 1（逐通道独立），官方脚本一般不改动它。需要作者核对实际配置后再做归类。
- **与数据的方向相反**：按这条假设，通道混合骨干上的 window、time、chan 应该相对更好，element 相对更差。但表 4（iTransformer）中 window 最差（−1.29），element 最好（−3.69）。这条"可能是不同骨干上最优单元不同的原因之一"至少应注明它与表 4 冲突，或者删去。

### 23. 表中数值（✅）

### 24. solar（✅，作为假设）

### 25. ETTh2、ETTm2（⚠️）

1. **κ 区分不了**：按草稿自己的起点带模型，$\kappa_{chan}=\kappa_{elem}=2T/(T+1)$，见第 8 条。只有"输入侧瞬态"或输入足迹这种结构，才会给出 $\kappa_{chan}=1<\kappa_{elem}$。而按第 22 条，后者在打分时刻的幅度可能很小。
2. **合并均值由 DLinear 主导，存在骨干混杂**：

   | ETTh2 MAE | window | time | chan | occ | elem |
   |---|---|---|---|---|---|
   | DLinear（表 5） | −7.47 | −5.89 | **−12.09** | −10.81 | −6.47 |
   | iTransformer（表 4） | −1.07 | −1.55 | −2.05 | **−2.42** | −2.37 |
   | TimeMixer（表 6） | −2.98 | −2.50 | **−3.84** | −3.23 | −2.99 |

   - 在 iTransformer 上，element ≈ occurrence，并且优于 channel row。"element 捕捉不到"并不是数据集的性质。
   - ETTm2 情况相同：只有 DLinear 上 chan（−13.46）胜过 occ（−11.71）。

   所以 §0.3 的"数据集困难结构"解读应改用逐骨干的表或秩，不能用表 1 的合并均值。
3. "T2、T5 的起点带"：T2 中没有定义"起点带"（它出现在 T1 的"注意"和 T5 的推论 12），引用位置要改。

### 26. ETTm1、weather（✅，作为假设）

三个骨干上 occurrence 都最好，与"目标侧单点困难"给出的 κ 排序（occ = elem < time、chan < win）大体一致。但目标侧结构下 $\kappa_{occ}=\kappa_{elem}=1$，所以 occ 与 elem 之间约 20% 的差距（ETTm1 上 −4.57 对 −3.73）不能由"目标侧"来解释。论文自己的解释是"同一目标的 occurrence 中也有预测得好的"，这正是 κ 之外的因素。

### 27. "零成本检验这些解读"（⚠️）

- 对齐指数按元素定义，在构造上就是目标侧结构，**不可能**检测到 ETTh2 所假设的上下文侧结构（第 11 条）。
- η² 的 $1/m$ 基线对预测残差无效（第 16 条）。
- 两者都必须按"骨干 × 数据集 × 步长"计算。

改用 occurrence 级的 $S_r$、质量捕获比和 top-r 重叠率之后，才能称得上"检验"。
