## 1. T1

### 1.1 引理 1 ✅

$\mathcal P\preceq\mathcal Q$ 时，$\mathcal Q$ 的每个块都是若干 $\mathcal P$ 块的并，所以 $\mathcal M_{\mathcal Q}(b)\subseteq\mathcal M_{\mathcal P}(b)$，最大值单调。正确。

**补充（与论文实现的关系）**：论文 §3.3 的预算是"每个单元屏蔽 $\lfloor rm+\tfrac12\rfloor$ 个**成员**"，不是 $b$ 个**项**。
- 等大块的单元，实际项数是 $m_{\mathcal P}\lfloor r\,|\mathcal P|+\tfrac12\rfloor$，与 $r|\Omega|$ 最多相差半个块（window 最多 $TD/2$ 项）；
- element 单元的块在序列两端更小，实际项数取决于选中了哪些 element。

所以不同单元之间的质量比较，**必须在相同实际项数 $s$ 下陈述**。差异的量级为 $O(m_{\max}/(r|\Omega|))$，可以忽略，但要写明。

### 1.2 引理 2 ⚠️（可以加强，并去掉"块等大"条件）

**加强后的陈述**：对**任意**划分 $\mathcal P$（块大小 $|B|$ 可以不同），把块按均值 $\bar e^2_B=\frac1{|B|}\sum_{\omega\in B}e^2_\omega$ 降序排列，取前 $k$ 个块，其并集大小为 $s_k$。那么在所有"$\mathcal P$ 块的并且总大小 $\le s_k$"的掩码中，这个前缀使移除质量 $F(S)=\sum_{\omega\in S}e_\omega^2$ **精确最大**。

*证明*：这是物品重量为 $|B|$、价值为 $\sum_B e^2$ 的 0-1 背包问题，按价值密度（即块均值）排序。其 LP 松弛在容量 $C$ 下的最优解是密度贪心：依次装满，最后一件取一部分。当 $C=s_k$ 时恰好装满前 $k$ 件、不需要取部分，所以 LP 最优值等于前缀的价值；而整数最优 ≤ LP 最优。∎

**推论（取代原文的"误差 ≤ 一个块"）**：element 单元的块均值前缀，在它**自己的实际项数**下，就是所有 element 掩码中的精确最优，没有误差项。

### 1.3 推论（移除质量的偏序）⚠️ → 精确版本

记 $M_{\mathcal P}(s)$ 为单元 $\mathcal P$ 在实际项数 $s$ 下（按论文规则）移除的残差质量。则对任意 $s$（在 $\mathcal P$ 可实现的项数上）：
$$M_{\text{occ}}(s)\ \ge\ M_{\text{time}}(s)\ \ge\ M_{\text{win}}(s),\qquad M_{\text{occ}}(s)\ \ge\ M_{\text{chan}}(s)\ \ge\ M_{\text{win}}(s),\qquad M_{\text{occ}}(s)\ \ge\ M_{\text{elem}}(s).$$

*证明*：由引理 2（加强版），$\mathcal P$ 的前缀是"$\mathcal P$ 块的并、大小 ≤ s"中的最优者。若 $\mathcal P\preceq\mathcal Q$，那么 $\mathcal Q$ 的前缀是 $\mathcal P$ 块的一个并（引理 1），所以它的质量不超过 $\mathcal P$ 在同一容量下的最优值。occurrence 是所有划分中最细的。∎

原文中的 "$M_{\text{occ}}\gtrsim M_{\text{elem}}$" 可以改成 "≥"（在相同项数下）。不同单元之间实际项数的取整差异，按 1.1 节的说明处理。

### 1.4 Hasse 图的措辞 ⚠️

- element 与 time column 不可比，需要 $D\ge2$ 且 $c(t)\ge2$；element 与 channel row、window 不可比，需要 $T\ge2$。（$D=1$ 时 time column 等于 occurrence；$T=1$ 时 element 和 channel row 都等于 occurrence。）实际设置都满足这些条件，但应写出来。
- **window ∧ element = occurrence**：✅。
- "element 是 occurrence 之上唯一不在 window 之下的粗化"：作为关于**全部划分**的命题是错的，因为有大量既比 occurrence 粗、又不在 window 之下的划分。应改为"**在五种单元中**，element 是唯一不细于 window 的单元"。

### 1.5 命题 3（κ 表）✅

逐格推导（内部情况，$c(t)=T$）：
- 单点 $(t,d)$：覆盖它的窗口有 $c(t)$ 个。time column 涉及 $c$ 个块、每块 $D$ 项，得 $\kappa=D$；channel row 是 $c\cdot T/c=T$；window 是 $c\cdot TD/c=TD$。**分子分母同时含 $c$，所以在序列两端也成立。**
- 跨通道同时刻事件：time column 是 $cD/(cD)=1$；channel row 是 $cD\cdot T/(cD)=T$；window 是 $c\cdot TD/(cD)=T$。**在序列两端也成立。**
- 单通道长度为 $\ell$ 的片段：目标集与片段相交的窗口满足 $i+L\in[t_0-T+1,\,t_0+\ell-1]$，共 $\ell+T-1$ 个。所以 channel row 是 $(\ell+T-1)T/(\ell T)$，window 是 $(\ell+T-1)D/\ell$，time column 是 $D$。**只对内部片段成立**；靠近序列两端时，分子分母都要按实际的 $c(t)$ 和窗口数重新计算（一般形式是：被触及块的项数之和除以 $\sum_{t\in\text{seg}}c(t)$）。
- 全通道片段：同理，window 和 channel row 都是 $(\ell+T-1)/\ell$，time column 是 1。

建议在表注中写明："单点和跨通道两行对所有 $t$ 成立；片段两行仅对内部片段成立。"

## 2. T2（命题 4）⚠️：模型过度参数化，方差份额不可识别

### 2.1 块均值恒等式本身 ✅
对可加模型逐块取平均是线性运算，表中"各单元得分 = 各效应块均值之和"是恒等式。对内部块：
- element 块和 channel row 块恰好覆盖全部步长 $k\in\{0,\dots,T-1\}$ 各一次，所以 φ 在这两类块中被平均成常数 $\bar\phi$ ✅；
- time column 块对应单一步长，保留 $\phi(k)$ ✅。

### 2.2 不可识别性 ❌（必须修正）

1. **φ 被 γ 完全吸收**：$\phi(t-i-L)$ 是 $(i,t)$ 的函数，而 $\gamma(i,t)$ 是定义在全部 $(i,t)$ 对上的自由函数，所以 $\gamma+\phi$ 只能作为一个整体被识别。
2. **α 的时间对齐分量被 γ 吸收**：$\bar\alpha(t)=\frac1D\sum_d\alpha(t,d)$ 也是 $(i,t)$ 的函数，同样落在 γ 的空间里。也就是说，solar 那种"跨通道同时刻"的困难，在这个模型里**分不清**是 α 还是 γ。（这一点在语义上反而说得通：对时间对齐的困难，time column 与 element 本来就看到同一个东西。）
3. **APC 线性混淆**：令 $t=i+L+k$。对每个通道 $d$，有 $a\cdot t=a\cdot i+a\cdot k+aL$，所以 $\{\alpha(\cdot,d),\beta(\cdot,d),\phi\}$ 可以同时加上 $(a t,\,-a i,\,-a k)$ 而不改变拟合，这就是年龄–时期–队列模型的经典识别问题（Fienberg & Mason, 1979；Holford, 1983）。而且 φ 很可能近似线性递增（误差随步长增大），**恰好落在被混淆的方向上**。

**修正方案**（任选其一，并写入论文）：
- (a) **加有界性约束**：若 $\|\beta(\cdot,d)\|_\infty\le B_\beta$，则别名斜率 $|a|\le 2B_\beta/n$，它对 φ 在 $k\in[0,T)$ 上造成的误差不超过 $2B_\beta T/n=O(T/n)$。滑窗设置下 $n\gg T$，误差可以忽略。陈述为："在 α、β 有界的条件下，φ 在 $O(T/n)$ 误差内可识别。"同时把 γ 定义为**与 k 的函数、与 t 的函数都正交**的交互项。
- (b) **换成与顺序无关的"单元可见度"**：对每个单元计算相关比 $\eta^2_{\mathcal P}=\mathrm{Var}(\text{块均值})/\mathrm{Var}(e^2)$，与纯噪声下的期望约 $1/m_{\mathcal P}$ 比较（或者用校正后的 $\omega^2$）。这个量定义唯一、不需要识别各效应，而且**直接回答"单元 $\mathcal P$ 能看到多少 occurrence 排序信息"**，是命题 4 想表达的意思的最干净版本。步长剖面 $\hat\phi(k)=$ 步长为 k 的平均残差，在方案 (a) 的约束下有 $O(T/n)$ 的边界误差。

### 2.3 "主要看见 X" 的解释需要尺度条件 ⚠️
- "element 主要看见 α"要求 β、γ 在 $T$ 个连续窗口上的局部平均接近常数，即上下文效应的变化尺度短于 $T$。若某个 regime 持续时间超过 $T$，平滑后的 β 会保留下来。
- "occurrence 在步长 k 处被屏蔽的比例随 φ(k) 单调增加"要求**非 φ 部分在不同步长之间同分布**（可交换性）；在此条件下，$P(X+\phi(k)>\tau)$ 关于 $\phi(k)$ 单调，结论成立。

### 2.4 点异常的"双重足迹" ⚠️
- 目标足迹：$c(t)$ 个 occurrence，大小约为 $M$，κ 见命题 3 ✅。
- 输入足迹（通道独立模型，输入包含 $t$ 的 $L$ 个窗口 × 全部 $T$ 个步长）：精确计算得
  - $\kappa_{\text{chan}}=1$，$\kappa_{\text{time}}=D$，$\kappa_{\text{win}}=D$；
  - $\kappa_{\text{elem}}=\dfrac{(L+T-1)T}{LT}=\dfrac{L+T-1}{L}$（$L=T$ 时约为 2）。

  所以原文"element 只能处理目标足迹"**说过头了**。准确的说法是：element 能以约 2 倍的项数代价覆盖输入足迹，但代价是要拿掉 $L+T-1$ 个**干净目标**的全部监督；channel row 则没有附带损伤。
- **通道混合骨干**（iTransformer、TimeMixer）：输入中的尖峰会影响所有通道的预测，输入足迹扩展为 $L\times T\times D$，这时它与 window 对齐（$\kappa_{\text{win}}=1$），而不是与 channel row 对齐。这个区别应写进去，它可能正是不同骨干上最优单元不同的原因之一。
- 足迹的幅度约为 $M|W_{kj}|$，只对线性模型精确，应标注"线性近似"。

## 3. T3

### 3.1 命题 5（T3a）

**恒等式** ✅：对非负随机变量 $X=|e|$，有 $\mathbb E X=\int_0^1 q(u)du$，并且 $\mathbb E X^2=\int_0^1 q(u)^2du$（$x\mapsto x^2$ 在 $x\ge0$ 上单调，所以 $X^2$ 的分位函数是 $q^2$）。定义 $\delta=1-q'/q$，即可得到原文两式。
- 需要 $q>0$ a.e.；在 $q=0$ 的区间上单独计入 $\int q'$。
- **注意**：这里比较的是**分位耦合**（边缘分布），$\delta(u)$ 不是"原来处于分位 u 的那些点改善了多少"。

**Chebyshev 步骤** ✅：$w_2/w_1\propto q$ 非降。若 $\delta$ 非增，则 $\mathrm{Cov}_{w_1}(\delta,q)\le0$，所以
$\mathbb E_{w_2}[\delta]=\mathbb E_{w_1}[\delta q]/\mathbb E_{w_1}[q]\le\mathbb E_{w_1}[\delta]$。
- 所需的**最弱条件**就是 $\mathrm{Cov}_{w_1}(\delta,q)\le0$，"δ 非增"只是它的一个充分条件。建议陈述时用协方差条件，因为极低分位的 δ 很可能有噪声，不满足单调。

**$2\delta-\delta^2$ 的处理** ✅：$h(\delta)=2\delta-\delta^2$ 在 $\delta<1$ 上递增，而 $\delta=1-q'/q<1$ 恒成立（因为 $q'>0$）。所以 δ 非增时 $h\circ\delta$ 也非增，Chebyshev 同样适用：$\mathbb E_{w_2}[h(\delta)]\le\mathbb E_{w_1}[h(\delta)]\le2\mathbb E_{w_1}[\delta]$。

**但原文的推论有缺口** ⚠️：由上式只能得到
$$-\Delta\text{MSE}_{\text{rel}}\ \le\ 2\,(-\Delta\text{MAE}_{\text{rel}}),$$
也就是 MSE 的相对改善**不超过** MAE 的 2 倍。**推不出 MSE 改善一定小于 MAE 改善**，因为平方带来的因子 2 与重加权的折扣方向相反。

- **反例（解析）**：令 $|e|\sim U[0,1]$，即 $q(u)=u$；取阶梯型 $\delta(u)=\delta_0\mathbf 1\{u\le0.9\}$（收益只在主体 90%），$\delta_0=0.1$。
  - $W_1=\int_0^{0.9}u\,du\big/\int_0^1u\,du=0.81$，$W_2=\int_0^{0.9}u^2du\big/\int_0^1u^2du=0.729$；
  - 于是 $\Delta\text{MSE}_{\text{rel}}/\Delta\text{MAE}_{\text{rel}}=(2-\delta_0)W_2/W_1=1.9\times0.9=1.71>1$。
  - 也就是说，**收益虽然只在主体，MSE 却动得比 MAE 多**。
- **正确陈述**：阶梯模型下，$\dfrac{\Delta\text{MSE}_{\text{rel}}}{\Delta\text{MAE}_{\text{rel}}}=(2-\delta_0)\dfrac{W_2(u^*)}{W_1(u^*)}$，其中 $W_j(u^*)$ 是主体 $[0,u^*]$ 在一阶矩、二阶矩中所占的份额。"MSE 动得少"**当且仅当** $W_2/W_1<1/(2-\delta_0)$，也就是尾部在二阶矩中的份额足够大（**重尾条件**）。一般情形下，该比值等于 $\mathbb E_{w_2}[h(\delta)]/\mathbb E_{w_1}[\delta]$。
- **对 solar 的解释** ✅（改为"可能"）：δ 在尾部为负时，$\mathbb E_{w_2}[h(\delta)]$ 可以为负，从而 MSE 上升而 MAE 下降。这是**可能**，不是必然。

**验证计划的修正**：
- 恒等式只对**单次运行的测试误差分布**精确成立。论文的表 2 是跨种子、horizon、数据集、骨干对**相对变化取平均**后的结果，比值的平均不能交换，所以"用平均后的分位剖面精确复现表 2"不成立。正确做法是：逐次运行应用恒等式，再按论文的方式平均。
- 只用 4 个分位点（median、q75、q90、q95）无法复现，需要完整分布。

### 3.2 命题 6（T3b）❌：条件写错，需要整体改写

**错误 1："右偏 ⇔ 中位数 < 均值"不成立。** 偏度（三阶矩）的符号不决定均值与中位数的大小关系。
**错误 2：双侧截断下，"右偏 ⇒ 截断均值 < 均值"不成立。** 论文的掩码是按 $|e|$ 选的，是**双侧**截断，而不是原文假设的"去掉上尾"。

**解析反例**：$Y=20$（概率 0.005），$Y=-2$（概率 0.2），$Y=0$（概率 0.795）。
- $\mathbb EY=0.1-0.4=-0.3$；中位数为 0（因为 $P(Y\le-2)=0.2<0.5\le P(Y\le0)$）。
- 三阶中心矩 $=0.005(20.3)^3+0.2(-1.7)^3+0.795(0.3)^3\approx41.83-0.98+0.02>0$，即**右偏**，但**中位数 > 均值**。
- 按 $|Y-\mathbb EY|$ 截掉 10%：偏差依次为 20.3（0.5%）、1.7（20%）、0.3（79.5%）。截掉的集合 R 是"20 的全部 0.5%"加上"−2 中的 9.5%"。
  - $\mathbb E[(Y-\mathbb EY)\mathbf 1_R]=0.005\cdot20.3+0.095\cdot(-1.7)=-0.06<0$；
  - 截断均值 $m_r=(-2\times0.105)/0.9=-0.233>\mathbb EY$，**向上**移动了。
- 结果：总体 MSE 仍然上升，增量为 $(m_r-\mathbb EY)^2\approx0.0044$；MAE 从 0.680 降到约 0.640（因为 $m_r$ 移向中位数）。

**正确陈述（命题 6′）**：设截断集合为 R，$P(R)=r$，对每个 $x$ 都用足够灵活、设定正确的模型。
1. 截断最小二乘的目标是 $m_r=\mathbb E[Y\mid Y\notin R]=\mathbb EY-\dfrac{\mathbb E[(Y-\mathbb EY)\mathbf 1_R]}{1-r}$。**偏移方向由 $\mathbb E[(Y-\mathbb EY)\mathbf 1_R]$ 的符号决定，与偏度无关。**
2. 总体 MSE 的增量恒为 $(m_r-\mathbb EY)^2\ge0$，等号成立当且仅当 $\mathbb E[(Y-\mathbb EY)\mathbf 1_R]=0$。
3. 若 $m_r$ 位于均值与中位数之间（包括端点），则总体 MAE 不增；在 $(m_r,\mathbb EY)$ 区间上有概率质量时严格下降。证明：$m\mapsto\mathbb E|Y-m|$ 是凸函数，最小值点是中位数，所以在中位数与均值之间单调。
- **可检验量**：不要用"残差偏度"，而应该直接测**被屏蔽残差的带符号均值**（截断集合的一阶矩），以及残差的**均值–中位数差**。

**错误 3："MSE 只能通过偏态通道上升"不成立。** 原文的"两条通道"应改为**三种效应**：
1. **污染或影响移除**：有限样本下降低估计误差，使 MSE 下降；
2. **信息损失**：被屏蔽的是干净且有信息量的项时，估计方差增大，使 MSE 上升（这正是 T8 讨论的 $\varepsilon=0$ 情形）；
3. **位置偏移**：截断集合一阶矩非零时出现，使 MSE 上升，增量见上式。

**新增命题 0（总体层面的 MSE 无免费午餐）✅（建议加入，证明只有一行）**：在任意模型类中，若训练分布与测试分布相同、优化精确，并且在总体上训练，那么全数据最小二乘的解 $\theta^*$ 是总体 MSE 在该模型类中的最小化者，所以任何掩码解 $\theta_S$ 都满足 $R_{\text{MSE}}(\theta_S)\ge R_{\text{MSE}}(\theta^*)$（对设定错误的模型也成立）。

**推论**：论文观察到的 MSE 改善（−1.7% 至 −2.8%）**只可能**来自
- (a) 有限样本、早停等估计效应（离群项通过共享参数在有限数据中扭曲了拟合）；或者
- (b) 训练集与测试集中高残差成分的分布不同（例如训练段的异常在测试段不再以同样方式出现）。

这一点应写进 §6 的讨论。它也让 S1 的论证更清楚：L1 和 Huber 同样受这条约束。

### 3.3 命题 7（T3c）⚠️

**代数** ✅：令 $|S|=r|\Omega|$，则
$\nabla\mathcal L_S=\frac{1}{1-r}\big(\nabla\mathcal L-\frac{2}{|\Omega|}\sum_S e\nabla f\big)$，
即 $\nabla\mathcal L_S-\nabla\mathcal L=\frac r{1-r}\nabla\mathcal L-\frac{2}{(1-r)|\Omega|}\sum_S e\nabla f$，与原文一致。上界 $\le\frac{2rG}{1-r}\,\overline{|e|}_S$ 正确；对 low end，$\overline{|e|}_{S_{\text{low}}}\le\sqrt{q_r(e^2)}$ 也正确。

**需要补充的条件**：
1. **"统一缩放对所有单元相同"只在全局归一化（即式 (4)）下精确成立。**
   - 实现中如果按 batch 归一化，batch 内的屏蔽比例 $r_b$ 是随机的，有效步长因子是 $\mathbb E[1/(1-r_b)]\approx\frac1{1-r}+\frac{\mathrm{Var}(r_b)}{(1-r)^3}$。
   - 对 window 单元，$\mathrm{Var}(r_b)\approx r(1-r)/B$（$B$ 为 batch 中的窗口数）；对 occurrence 单元，约为 $r(1-r)/(BTD)$。所以两者有**二阶差异**，量级为 $O(r/B)$。
   - 用 Adam 时，常数尺度的梯度缩放基本被逐坐标归一化吸收，这一项更可以忽略。应写明这一点，并说明论文实现采用的是哪种归一化。
   - element 单元因为序列两端的块较小，实际的 $|S|/|\Omega|$ 不严格等于 r，因子也会略有不同（量级为 $O(T/n)$）。
2. **上界只对当前参数 $\theta$ 成立**：应写成 $\overline{|e(\theta)|}_S$。被屏蔽的 low end 项在训练中不再接收梯度，它们的残差**有可能上升**，所以"low end 无效"需要假设：沿训练轨迹，$\overline{|e(\theta_t)|}_{S_{\text{low}}}$ 保持很小。这个量可以在训练中记录下来检验。
3. **逐步的小扰动推不出最终模型几乎不变**：对光滑损失，轨迹偏差的上界会随训练步数指数放大（Grönwall 型）。所以"low end 在构造上近乎无效"只能作为**一阶或启发式**论证。论文中应写成"每一步的梯度扰动很小"，而不是"最终模型不受影响"。
4. **建议改用更紧、更有解释力的 Cauchy–Schwarz 形式**：
   $$\Big\|\tfrac{2}{(1-r)|\Omega|}\sum_{S}e\nabla f\Big\|\le\tfrac{2}{(1-r)|\Omega|}\Big(\sum_S e^2\Big)^{1/2}\Big(\sum_S\|\nabla f\|^2\Big)^{1/2}.$$
   它直接以**移除的残差质量** $\sum_S e^2$（就是 T1 中的量）为尺度，把 T1 与 T3c 联系起来，而且避免了用 $G=\max\|\nabla f\|$ 带来的松弛。

### 3.4 命题 8（T3d）⚠️

**第 1 点（理想掩码下的 LS）** ✅，需要补条件：理想掩码等于污染的支撑，并且与 $(x,\xi)$ **独立**。否则按残差选出的掩码会对 $\xi$ 产生选择效应，引入截断偏差（这正是命题 6′ 的机制）。渐近协方差为 $\sigma^2(\mathbb E xx^\top)^{-1}/((1-\varepsilon)n)$。

**第 2 点（L1 的偏差阶）** ✅：在单侧远端污染下，混合分布的中位数 $m$ 满足 $(1-\varepsilon)F_\xi(m-\mu)=\tfrac12$，所以
$m-\mu=F_\xi^{-1}\!\big(\tfrac1{2(1-\varepsilon)}\big)=\mathrm{med}(\xi)+\dfrac{\varepsilon}{2f_\xi(\mathrm{med})}+O(\varepsilon^2)$。
偏差与 $M$ 无关、阶为 $O(\varepsilon)$。对称污染时偏差为 0。LAD 的渐近方差约为 $1/(4(1-\varepsilon)^2f_\xi(\mathrm{med})^2n)$。

**第 3 点（高斯下的效率比 π/2）** ✅：$f(0)=1/(\sigma\sqrt{2\pi})$，所以 $1/(4f^2)=\pi\sigma^2/2$。
- 与理想掩码 LS 相比，方差比为 $\dfrac{\pi/2}{1-\varepsilon}$。

**"Huber 介于两者之间"** ❌：在**单侧大污染**下，Huber（ψ 单调有界，不重下降）的位置估计满足
$(1-\varepsilon)\,\mathbb E\psi_c(\xi-m)+\varepsilon c=0$，即
$$m\approx\frac{\varepsilon c}{(1-\varepsilon)(2\Phi(c)-1)}.$$
- $c=1.345$ 时，系数为 $1.345/0.8214\approx1.64$，**大于**中位数的 $\sqrt{2\pi}/2\approx1.25$。
- $\varepsilon=5\%$ 时，Huber 的渐近偏差约为 0.086，中位数约为 0.066。
- 这与 Huber 的极小极大理论一致：在 ε-污染下，中位数使最大偏差最小。

**修正后的陈述（命题 8′）**：
1. **关键区别在于 ψ 函数的形状**。掩码是**硬拒绝、重下降型**估计量：一旦正确识别出污染，渐近偏差为 0。L1 和 Huber 是**单调型**估计量，在**非对称**大污染下保留 $O(\varepsilon)$ 的非零偏差，并且不随 $n$ 消失（系数分别约为 1.25 和 1.64，后者在 $c=1.345$、高斯噪声下取得）。
2. **对称污染时**，三者都无偏，只比效率：理想掩码 LS ≈ Huber（$c=1.345$ 时效率约 95%）> L1（效率 $2/\pi\approx64\%$）。
3. **对 E1 的含义**：掩码相对 Huber 的优势**取决于污染的不对称程度**。可检验量与命题 6′ 相同，即被屏蔽残差的带符号均值。
4. **关于"MSE 和 MAE 都优于 L1"**：要区分测试集是否被污染。
   - 测试集干净或对称污染时，结论成立：估计误差越小，两个指标都越好（高斯情况下，$\mathbb E|\xi+\Delta|$ 随 Δ 的离散度增加而增加）。
   - 测试集被**非对称**污染时，L1 的目标（被污染分布的中位数）在总体 MAE 上有 $O(\varepsilon^2 f)$ 的优势，而掩码 LS 的效率优势是 $O(p/n)$ 量级。两者孰大取决于 $\varepsilon^2$ 与 $p/n$ 的相对大小，应如实陈述。
   - Huber 的"约 95% 效率"在对称情况下使它非常接近理想掩码，所以**命题 8′ 预测 E1 中 Huber 在对称污染的数据集上会是最强的基线**。
